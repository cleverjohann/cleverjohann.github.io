Lumi — Asistente educativo de escritorio

App de escritorio nativa tipo overlay flotante para acompañar el estudio sin distracciones

Asistente de escritorio pop-out ultra ligero: una ventana flotante transparente que acompaña al estudiante en su sesión de estudio sin interrumpir el flujo de trabajo, con sincronización de estado reactivo en tiempo real y mínimo consumo de recursos.

Tecnologías Utilizadas
  • Tauri 2
  • Rust
  • Vite
  • Convex (Realtime)
  • TypeScript
  • Consumo mínimo de memoria: ~30MB de RAM frente a los 250MB+ de Electron gracias a Rust y Tauri 2.
  • Backend reactivo con Convex: Sincronización de notas, consultas e historial de estudio al milisegundo sin sockets pesados.
  • Ventana Always-on-top: Gestión de ventanas nativas con IPC de Tauri para posicionamiento flexible en pantalla.

DocuGraph

Editor de documentación atómica + grafo de dependencias + servidor MCP para agentes de IA

Herramienta multiplataforma para escribir documentación atómica y viva, visualizar el grafo de dependencias entre especificaciones y exponer ese contexto a agentes de código (Cursor, Windsurf, Claude) mediante un servidor MCP (Model Context Protocol) implementado en Kotlin Multiplatform.

Tecnologías Utilizadas
  • Kotlin Multiplatform
  • Model Context Protocol (MCP)
  • Dependency Graphs (DAG)
  • AI Agent Context Bridge
  • Atomic Markdown Docs
  • Grafo de dependencias interactivo: Detección automática de inconsistencias, documentos huérfanos y contratos rotos.
  • Servidor MCP en Kotlin: Expone herramientas como get_doc_context y query_dependencies para alimentar agentes inteligentes.

Sobre mí

Perfil profesional, enfoque de ingeniería y compromiso técnico.

Mi nombre es Clever Johann Machaca Asto, soy Ingeniero de Sistemas e Informática originario de Arequipa, Perú. Mi principal pasión profesional es construir y llevar productos reales a producción, asumiendo la responsabilidad del ciclo de vida completo: desde el modelado del dominio y la persistencia de datos, hasta la experiencia de usuario y el despliegue en la nube.

Tengo un enfoque riguroso en el diseño de APIs robustas, limpias y resilientes, aplicando buenas prácticas como arquitectura modular, migraciones controladas, pruebas automatizadas y patrones de integración seguros. Integro tecnologías de Inteligencia Artificial (LLMs, RAG, pgvector y servidores MCP) cuando aportan una solución práctica y medible a las necesidades del usuario final.

🚀 Enfoque actual: Abierto a oportunidades como Full-Stack Engineer o Backend Developer en proyectos remotos o presenciales, así como a colaborar en iniciativas innovadoras y hackathones internacionales.
